# Mani

ترجمة عربي ⇄ بروندي (Kirundi) على تلفون واحد، أندرويد.

- **تنزيل:** <https://github.com/DrOmaia/mani/releases/latest> ← `Mani.apk`
- النصف السفلي للعربي (كتابة أو صوت 🎤، وبيقرأ الترجمة العربية بصوت عالي 🔊).
- النصف العلوي (مقلوب) للبروندي: كتابة فقط، والترجمة بتطلع مكتوبة.
- ⭐ جمل جاهزة (بتضيفي وبتحذفي)، ✅ شاشة مهام للخدامة بالبروندي، 🕘 سجل محفوظ للأبد، ↩︎ ترجمة عكسية، ⇅ قلب الشاشة.
- 🧹 أعمال: أزرار بصور إيموجي كبيرة للخدامة، تضغطها فتطلع الترجمة بالبروندي فوق.
- ✅ مهام «كل يوم» (🔁) بترجع غير منجزة كل يوم جديد.
- 💬 ردود: أزرار جاهزة للخدامة فوق (نعم، لا، شكراً، ما فهمت، تعبانة، جوعانة، أحتاج مساعدة)، وللبيت بزر 💬 ردود تحت.
- ⚙️ إعدادات: الوضع الليلي، وحجم الخط (صغير / وسط / كبير).
- 🎤 عند الخدامة بالسواحيلي (البروندي ما في إله تعرّف صوت).
- الترجمة من Google Translate المجانية (بدها إنترنت).
- كل push على `main` بيبني APK جديد عبر GitHub Actions.

## التحديث
- كل نسخة جديدة بتطلع لحالها، والتطبيق بيعرض شريط «في نسخة جديدة». اضغطي عليه، ثبّتي الملف، وبيتحدّث فوق القديم بدون ما ينمسح.
- ملف التحديث بينحذف لحاله من التلفون بعد التحديث، وعلى GitHub بيضل بس آخر نسخة والنسخة المستقرة.
- إذا نسخة جديدة خربت: Actions ← Build APK ← Run workflow ← `restore-stable` (بيرجع آخر نسخة علّمتيها `mark-stable`).
